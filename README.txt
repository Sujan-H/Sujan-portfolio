PROMPTCRAFT WEBSITE BUILDER

1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html with Live Server (or double-click index.html).
4. Type a description or choose an example, then click Generate website.
5. Preview the generated page, copy the HTML, or download it.

Note: This is a front-end demo with built-in prompt matching. It does not call an AI model or generate arbitrary code from a live AI service.
